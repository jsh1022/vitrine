# Redesigned UI의 iPad 배치 보정

Retrine beta.35·38·39에서 보고된 음악 화면의 iPad 문제를 기준으로 현재
Vitrine의 배치를 보정했다. 팟캐스트 관련 변경은 포함하지 않는다.

- 홈 필터의 가로 위치를 현재 헤더 폭 안으로 제한하고, 피드가 늦게 도착해도
  상단 배경을 연결한다. 배경 폭은 현재 페이지 폭을 따른다.
- 탭 바 높이 캐시는 폭이나 가로 크기 클래스가 바뀌면 다시 측정한다.
  긴 탭 이름은 기존보다 더 축소할 수 있게 한다.
- 가로로 나란히 배치된 플레이리스트 커버와 메타데이터는 각 열의 폭을 유지한다.
  헤더 폭이 바뀌면 이전 크기에서 측정한 높이 캐시를 버린다.
- 넓은 화면의 고정 ⋯ 버튼은 같은 창에 표시된 내비게이션 바가 있으면
  그 바의 세로 중심에 맞춘다. 없으면 기존 안전 영역 기준을 사용한다.
- 플레이어 음질 표시는 넓은 화면에서 시간 라벨이 없어도 표시하며,
  짧은 재생바 컨테이너에 잘리지 않도록 더 넓은 부모 뷰에 배치한다.
- 별도 창에 옮기는 Spotify 메뉴의 팝오버 기준 뷰도 해당 창으로 옮긴다.
  UIKit이 실제 표시를 받아들이지 않은 요청은 기존 3초 제한에서 실패 처리한다.

## 확인 범위

수정한 제품 소스 7개는 iPhoneOS SDK의 arm64 대상으로 Logos 변환 및
`-fsyntax-only -Wall -Werror` 검사를 통과했다. 레이어 검사와 `git diff --check`,
Mac에서 실행하는 홈 배치 계산 검사도 통과했다.

사용자 요청으로 시뮬레이터 실행 검증은 생략했다. 추가한 음질 표시 UI 회귀
검사도 실행하지 않았다. 실제 iPad의 회전·분할 화면·메뉴·터치 동작은 미확인이다.
탭 바 아래 검은 띠는 현재 코드에서 원인을 확정하지 못했으며 해결 완료로
간주하지 않는다. IPA 생성·설치·커밋·푸시는 하지 않았다.
