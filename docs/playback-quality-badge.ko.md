# 재생바 아래 음질 배지

기본 화면과 Redesigned 화면의 재생바 아래, 양쪽 시간 표시 사이에 작은 회색 배지를 표시합니다.
배지를 누르면 음질, 원본 샘플레이트, 출력 샘플레이트, 리샘플링, 소스를 보여주는 팝오버가 열립니다.
팝오버의 상세 재생 정보 버튼은 기존 Playback details 화면으로 이동합니다.

최근 외부 PCM 교체가 확인된 경우에만 파일 디코더 정보로 무손실을 표시합니다.
16비트 초과이면서 48 kHz를 초과하는 파일은 고해상도 무손실로 표시합니다.
공급자의 96 kHz 주장만 있고 실제 파일이 48 kHz라면 48 kHz 무손실로 표시합니다.
Spotify 자체 스트림의 음질이 확인되지 않은 경우에는 배지에 Spotify를 표시하고,
팝오버의 확인하지 못한 값은 확인 불가로 남깁니다. 일시정지나 재정렬로 최근 재생 확인이
없어진 경우에도 무손실임을 추정하지 않습니다.

배지의 음질은 원본 파일 형식입니다. 파일·앱·장치 사이의 레이트 변환은 리샘플링 항목에
따로 표시합니다. 무손실 배지나 레이트 일치 자체가 전체 출력의 bit-perfect를 증명하지 않습니다.

Native와 Redesigned는 각각 자기 레이어의 훅과 배지를 사용합니다. 표시 데이터와 독립적인
팝오버만 Shared에 둡니다. 기존 DurationElementUnit 클래스와 시간 표시 식별자는
제공받은 Spotify 9.1.90 바이너리 및 기존 재생 화면 코드의 기록에서 확인했습니다.
Spotify의 재생바 크기나 스택을 바꾸지 않으며, 배치를 확인할 수 없는 화면에는 배지를 추가하지 않습니다.
재생바를 그리는 매 프레임 대신 화면이 표시되는 동안 1초 간격으로 갱신합니다.

검증: 변경한 Objective-C와 Logos를 로컬 iOS SDK로 arm64 컴파일했고 레이어 규칙과 문법을
확인했습니다. 시뮬레이터 하네스에는 두 화면 모드 각각 배지 배치·탭·팝오버·상세 화면 이동과
공급자 메타데이터만으로 무손실을 표시하지 않는 검사를 추가했습니다.
로컬에는 Xcode가 없어 이 실행 검사는 GitHub Actions에서 확인해야 합니다.
